# cu-studio

Creative Upaay social content: story in, Instagram posts out (carousels, then 30-90 s reels), in the CU Social design system.
Usually run from **CU Studio**, a local web UI where Claude Code does each step and you approve it.

```bash
npm run studio   # → http://localhost:4321
```

- **New machine:** follow [SETUP.md](SETUP.md).
- **Rules, layout and pipeline:** [CLAUDE.md](CLAUDE.md).
- **Brand book:** [design-system/project/README.md](design-system/project/README.md).

Private repo: it contains team photos and internal stories.
