# ShiftSlide

A before/after pair that shows the change in one glance.

**JSON:** `{ "type": "shift", "label", "text?", "before", "after", "beforeLabel?", "afterLabel?" }`.

- Before sits on a plain `cu-card`. After sits on `cu-card--accent` and may carry the slide's one ==highlight==.
- Keep both sides the same length, max 15 words each.
