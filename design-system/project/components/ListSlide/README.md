# ListSlide

A headline with 3–5 sparkle bullets, for features, steps or lessons.

**JSON:** `{ "type": "list", "label", "text", "items": [] }`.

- Items: max 8 words each, parallel grammar.
- The ✦ marker is the sparkle from creativeupaay.com, in `accent`.
- More than 5 items means split the list across two slides.
