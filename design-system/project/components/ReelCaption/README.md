# ReelCaption

Burned-in captions: 2–5 words at a time, with the spoken word highlighted.

- `type-reel-caption`, white with a midnight shadow, centred, 120px above the bottom safe line.
- The active word gets `highlight` with `on-highlight` text (`.cu-caption .on`).
- Lowercase is fine. No emoji in captions. Keep punctuation minimal.
- Many people watch with the sound off, so every reel ships with captions.
