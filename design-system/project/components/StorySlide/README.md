# StorySlide

One beat of the story: a chapter label, a headline and up to 35 words of body.

**JSON:** `{ "type": "story", "label", "text", "body" }`. Theme defaults to `paper`.

- `label` numbers the chapter (`01 / The problem`), because a story is a sequence.
- `text` in `type-headline`, max 12 words. Use *accent* on one phrase.
- `body` in `type-body-lg` / `ink-soft`, max 35 words.
- One idea per slide. If you need "and also", make it two slides.
