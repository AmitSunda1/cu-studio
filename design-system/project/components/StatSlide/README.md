# StatSlide

One big number with what it means. Use it for the result of a story.

**JSON:** `{ "type": "stat", "label", "value", "unit", "text", "body" }`. Theme defaults to `ultraviolet` (the number in marigold).

- `value` is the number only (`70`). `unit` goes in small type (`%`, `+`, `x`, `hrs`).
- `text` says what the number measures, in plain words.
- Use only real, sourced numbers: client results or creativeupaay.com stats. Never round up.
