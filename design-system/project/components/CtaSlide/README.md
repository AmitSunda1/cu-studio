# CtaSlide

The last slide, with one clear ask, the action pills and the wordmark.

**JSON:** `{ "type": "cta", "label", "text", "actions": [] }`. Theme defaults to `ultraviolet`.

- `text` is a question the reader can answer yes to, tied back to the story.
- `actions`: 2 pills max. The first is filled (the primary ask). Asks that work: Save this, Send to a founder, DM us "AUDIT", Follow for build stories.
- Uses the real Creative Upaay wordmark file (shown white on Ultraviolet).
