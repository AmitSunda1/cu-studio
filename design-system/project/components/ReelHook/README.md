# ReelHook

The on-screen hook card for a reel's first 1.5 seconds, also used as the reel cover.

**Canvas:** 1080 × 1920. Text stays inside the safe zone: `reel-safe-top` 250px, `reel-safe-bottom` 440px, `reel-safe-right` 150px. The cover hook also stays inside the centre 1440px (`reel-cover-crop`) so the grid shows it.

- The hook sits on a solid `ground` card (any theme) over the video, so it reads on any footage.
- Max 9 words. The ==highlight== goes on the stake.
- The guides in this preview are for layout only. Never export them.
