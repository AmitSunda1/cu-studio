# HookSlide

The first slide of every carousel: it has to stop the scroll and earn the swipe.

**JSON:** `{ "type": "hook", "label", "text", "sub" }`. Theme defaults to `midnight`.

- `text`: 4–9 words in `type-hook`, at most 4 lines. Lead with tension, a number or a stake ("One missed date. One malpractice claim.").
- Put ==highlight== on the 1–3 words that carry the stake. Only one highlight per slide.
- `label`: the case file or topic in mono caps (`CASE FILE / LEGAL`).
- `sub`: one sentence that promises the payoff.
- The footer shows the **Swipe →** pill only on slide 1.

**Don't** start with the company name, a greeting or "In today's post". Keep the hook inside the centre 1012px (`grid-crop-width`) so the 3:4 profile grid doesn't cut it.
